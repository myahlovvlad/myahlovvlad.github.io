# myahlovvlad.github.io

Bilingual GitHub Pages landing page for Vlad Myahlov's professional biography and selected engineering cases.

## Public URL

`https://myahlovvlad.github.io/`

## Structure

- `index.html` — bilingual landing page.
- `styles.css` — responsive visual system with light and dark themes.
- `script.js` — RU/EN language switch, theme preference and reveal effects.
- `assets/favicon.svg` — site icon.
- `.github/workflows/pages.yml` — official GitHub Pages deployment workflow.
- `.nojekyll` — disables Jekyll processing for the static site.

## Publish

1. Create a public repository named exactly `myahlovvlad.github.io`.
2. Upload these files to the `main` branch.
3. Open `Settings → Pages`.
4. Set `Source` to `GitHub Actions`.
5. Run or re-run the `Deploy static portfolio to GitHub Pages` workflow.

## Editing cases

Engineering case cards are maintained directly in `index.html`. Public research prototypes should link to their repository and bilingual README files when available.

# Portfolio Media Evidence Requests

The portfolio should use real engineering evidence, not stock images or decorative AI illustrations. This file lists the media that would materially strengthen the current pages.

## Priority 1 — SpectroNex / scientific instrument control

Target: `/cases/instrument-control-software.html` and homepage flagship block.

Please provide:

1. **One clean photo of the real test setup**
   - instrument visible;
   - PC/laptop may be visible;
   - no serial numbers, customer labels, internal documents or confidential stickers;
   - landscape orientation preferred, at least 1600 px wide.

2. **2–3 application screenshots**
   - connection/device screen;
   - Spectrum Scan configuration/workspace;
   - completed spectrum/result view;
   - remove usernames, credentials, serial numbers and private file paths.

3. **One representative spectrum plot**
   - real or sanitized test run;
   - axes and units visible;
   - no customer sample identifiers;
   - PNG/SVG or source CSV if available.

4. **Optional 10–20 s muted demo clip**
   - configuration → run → result;
   - WebM/MP4 source is acceptable; final site asset will be compressed.

## File format guidance

- Photos: original JPEG/HEIC/PNG; final site conversion can be WebP/AVIF.
- UI screenshots: PNG preferred.
- Diagrams: SVG/PDF/source format preferred.
- Plots/data: SVG/PNG plus CSV/XLSX source where publication is allowed.
- Video: original MP4/WebM; final site clip should be short, muted and compressed.

## Confidentiality checklist before upload

Remove or hide:

- passwords, tokens, API keys;
- names of customers and private contacts;
- serial numbers and unique device identifiers;
- private repository URLs when not already public;
- local file paths containing personal information;
- signatures and internal approval metadata;
- unpublished drawings, source code or vendor-confidential details.

PRIVATE PROTOTYPE · SANITIZED CASE

Engineering automation should preserve approvals, provenance and evidence.

A local-first desktop agent prototype indexes files on the user’s machine, searches locally, prepares an external research request, requires explicit approval and saves both the result and an evidence manifest.

Default modeObserve / constrained
Local layerIndex + search + model routing
External layerApproval-gated delegation
EvidenceAudit + report + manifest
01 / Control loop

Local context first, external action only through an explicit gate.

01Indexlocal files
02Searchlocal evidence
03Prepareresearch request
04Approvesingle-use gate
05Delegateexternal tool
06Preserveresult + manifest

The prototype deliberately starts with a narrow vertical slice instead of unrestricted computer control. Local model calls and external delegations are recorded so the resulting report can be tied back to the operations that produced it.

02 / Safety boundary

Agentic capability is introduced behind explicit controls.

The implemented prototype does not grant itself unrestricted shell access, software installation, device writes or arbitrary upload capabilities. Those actions belong to later phases only after an approval broker and stronger supervisor model exist.

03 / Proof

What this case proves.

It demonstrates agent-system architecture, local-first information retrieval, explicit human authorization, auditability and evidence packaging — the same verification-oriented mindset used in scientific-instrument work applied to AI automation.

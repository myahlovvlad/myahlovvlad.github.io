RESEARCH ALPHA · PUBLIC REPOSITORY

Computational chemistry as a traceable software workflow.

Q2SC explores how molecule preparation, quantum calculations, QSAR/QSPR, chemometrics and analytical interpretation can live inside one explicit software architecture instead of disconnected notebooks and scripts.

The public repository separates a FastAPI orchestrator, heavy calculation worker and React/Electron interface. The core engineering idea is to make scientific assumptions, methods and outputs explicit and traceable.

02 / Boundary

A running calculation is not a validated scientific claim.

The repository contains a real PySCF calculation path, while predictive models and spectral profiles remain research-grade and require validation against appropriate experimental data. This limitation is part of the product model, not hidden marketing copy.

03 / Proof

What this project proves.

Q2SC demonstrates scientific-software architecture, domain modelling, separation of heavy compute from application orchestration and disciplined communication of model limitations.

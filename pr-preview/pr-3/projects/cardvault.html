Vlad Myahlov/Projects/CardVault

PRODUCT PROTOTYPE · PUBLIC REPOSITORY

OCR is only useful when uncertain recognition becomes a controlled user workflow.

CardVault turns a photo of a business card into a structured contact through OCR, field classification and mandatory user confirmation, then keeps the result local-first and portable across desktop and mobile targets.

01 / Workflow

Recognition is a proposal, not ground truth.

01Capturefront · back · other
02OCRrus + eng
03Classifyname · company · contacts
04Confirmhuman correction
05Store / sharelocal · JSON · CSV · vCard

The important product decision is the confirmation boundary: OCR never silently overwrites the structured record. The user remains the final authority for ambiguous text and field assignment.

02 / Cross-platform

One application model across web, desktop and mobile targets.

The project uses a shared Tauri/React frontend and supports Windows and Android release workflows, Linux/macOS desktop targets, plus an iOS simulator build in GitHub Actions. Current storage is local IndexedDB with explicit JSON backup/import; cloud multi-user synchronization is roadmap, not a published capability.

03 / Proof

What this project proves.

CardVault demonstrates product workflow design around uncertain machine output, cross-platform packaging, local-first data handling, mobile/desktop UX and honest separation between implemented capability and roadmap.
